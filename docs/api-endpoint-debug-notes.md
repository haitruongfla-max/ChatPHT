# Chẩn đoán endpoint Android

Ngày 23-08-2026, việc mở tên miền triển khai hiện có trả trang bảo trì và endpoint API sandbox đang cấu hình trả trang tạm thời không khả dụng. Đây là nguyên nhân phù hợp với lỗi `Failed to fetch` ở Trợ lý AI và việc tìm người dùng không ổn định trên APK. Đã khởi động lại dịch vụ quản lý dự án để xác minh lại endpoint trước khi thay đổi cấu hình Android. Không ghi URL, khóa hay dữ liệu nhạy cảm vào tài liệu này.
